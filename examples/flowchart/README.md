# 📊 Flowchart Examples

Open any file in this folder in Momiji IDE, then click the **📊 Flowchart**
button in the editor toolbar (appears for `.js`, `.ts`, and `.py` files).

The flowchart updates **live** as you edit the code.

| File | Shows |
|------|-------|
| `grade.js` | A clean if / else-if decision chain |
| `fizzbuzz.js` | A `for` loop with nested conditions |
| `login_check.py` | A `while` loop with a counter and a decision |

## Reading the diagram

| Shape | Meaning |
|-------|---------|
| 🟢 Rounded (green) | Start |
| 🔴 Rounded (red) | End / return |
| ▭ Rectangle | A statement (assignment, calculation) |
| ◆ Diamond (yellow) | A decision — `if`, `while`, `for` condition |
| ▱ Parallelogram (teal) | Input / output — `print`, `console.log` |

Edge colors: **green = yes/true**, **red = no/false**, **teal = loop back**.
