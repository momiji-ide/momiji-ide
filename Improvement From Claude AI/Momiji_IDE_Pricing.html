Frequently asked questions

Is Momiji IDE really free forever? +
Yes. The core IDE — Block editor, Flow editor, Code editor, sandbox, Git, and all tools — will always be free. The free tier uses Groq's free API tier for Kitsune AI (50 req/day). No account, no credit card required to download and use.
What is BYOK? Do I need to pay for AI? +
BYOK = Bring Your Own Key. You connect your own API keys (Claude, Gemini, OpenAI, etc.) directly in Momiji settings. Keys are stored locally on your machine — never on our servers. This means AI costs go through your own account, giving you full control and transparency.
What is Kitsune AI? Is it a custom model? +
Kitsune is the AI persona and assistant built into Momiji IDE. It's not a new foundation model — instead, Kitsune is a smart routing and prompting layer that works with 8 different AI providers (Claude, Gemini, GPT, Groq, OpenRouter, DeepSeek, Mistral, Ollama). You can switch providers anytime. The "Kitsune" experience — context awareness, agents, memory — works regardless of which provider powers it.
When will paid tiers launch? +
Pro and Studio tiers are planned once we reach significant traction. The philosophy is: build community trust first, monetize power users second. You'll be notified via the in-app update system when tiers go live. Early users may receive founding member discounts.
Is Momiji IDE open source? +
Yes! Momiji IDE is open source on GitHub. You can inspect the code, contribute features, report issues, or fork the project. The source is available at github.com/momiji-ide/momiji-ide.
Does it work on all operating systems? +
Yes. Momiji IDE v1.2.0 ships as native desktop apps for Windows (x64), macOS (Intel + Apple Silicon M1/M2/M3), and Linux (AppImage). All downloads are available free at the GitHub Releases page.
